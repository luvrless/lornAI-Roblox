# lornAI - Roblox Studio Agent Extension

Browser extension for the lornAI Roblox Studio Agent.

Website: https://lorn.lol  
Telegram: https://t.me/logmade  
Repository: https://github.com/luvrless/lornAI-Roblox

## Installation

1. Open `chrome://extensions` or `edge://extensions` in your browser.
2. Enable **Developer mode** in the top right.
3. Click **Load unpacked** and select this directory.
4. Run `start.bat` from the root directory to connect to Roblox Studio.
